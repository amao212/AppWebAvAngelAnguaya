# 2026-10-28 — PoliMusic V2 Song Page Implementation

1. **Entities/Song.cs** — Created Song entity matching TBL_SONG (ID, Name, Path, Plays)
2. **DAL/Song.cs** — Full CRUD: Save, Read (with ROW_NUMBER for track number), ReadByName, ReadById, Update, IncreasePlays, Delete, CheckExistSong. All queries use SqlParameter.
3. **BLL/Song.cs** — Business layer delegating to DAL, includes ToEntity(DataRow) converter.
4. **css/estilos.css** — Spotify-style dark theme with CSS variables palette, sidebar layout, pill buttons, round play button, responsive design.
5. **img/logo.svg** — PoliMusic music note logo in accent orange.
6. **js/reproductor.js** — Pure JS audio player: play/pause per track, prev/next, progress bar, volume, equalizer animation, keyboard shortcuts, mobile sidebar toggle.
7. **Song.aspx** — Full page: sidebar (logo, nav, user info, logout), welcome header with authenticated user name, search bar, song list (ID/Nombre/Ruta/Reproducciones/Duracion), fixed bottom player.
8. **Song.aspx.cs** — Auth check via session, song list loading from BLL, search filter, play count increment via async XHR, JSON generation for player JS, file path resolution helpers.
9. **Song.aspx.designer.cs** — All control declarations.
10. **WebAppPoliMusicV2.csproj** — Registered all new files (Entities/Song.cs, BLL/Song.cs, DAL/Song.cs, Song.aspx + deps, css/estilos.css, img/logo.svg, js/reproductor.js).

## Key Decisions
- Renamed `MapPath` to `MapPathSeguro` to avoid CS0108 warning (hiding Page.MapPath)
- Track number derived via SQL `ROW_NUMBER()` since TBL_SONG has no NUM_PISTA column
- Audio file existence checked server-side; if missing, `data-src` is empty and JS shows "--:--"
- Play count incremented via async XHR to `Song.aspx?accion=reproducir&id=X`
- Compiler blocked by sandbox; verified correctness via static review against existing code patterns
